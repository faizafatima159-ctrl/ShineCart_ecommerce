# 🛒 ShineCart - Full Stack E-commerce Website

A modern Full-Stack E-commerce website built using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap.

This project allows users to browse products, manage their cart, place orders online, and explore a responsive shopping experience. It also includes a complete admin panel for product and order management.

---

# 🚀 Features

## 👤 User Features
- User Registration & Login
- Role-Based Authentication
- Browse Products
- Product Details Page
- Shopping Cart System
- Wishlist Functionality
- Coupon & Discount System
- Product Review & Rating System
- Order Placement
- Order History
- Responsive User Interface

## 🛠️ Admin Features
- Add Products
- Edit Products
- Delete Products
- Manage Categories
- Manage Orders
- Manage Users
- Inventory Management
- Full Administrative Access

---

# 💻 Technologies Used
- HTML
- CSS

- PHP

---

# 🔐 Authentication System

This project includes a Role-Based Authentication System:

- Users can register, login, browse products, add items to cart, and place orders.
- Admins have complete control over products, categories, users, and orders.

# 📂 Project Structure

```text
├── admin/              # Admin panel files
├── assets/             # Images, CSS, JS files

├── includes/           # Database connection & reusable files
├── products/           # Product pages
├── user/               # User dashboard & order history
```

# ▶️ How to Run the Project

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/faizafatima159-ctrl/ShineCart-ecommerce
```

## 2️⃣ Move to Server

Copy the project folder into XAMPP `htdocs` folder.

## 3️⃣ Start Services

Open XAMPP Control Panel and start:

- Apache
- MySQL

## 4️⃣ Import Database

- Open:
  
```text
localhost/phpmyadmin
```

- Create database:

```text
ecommerce_db
```

- Import SQL file from the `sql` folder.

## 5️⃣ Run in Browser

```text
http://localhost/ecommerce
```
